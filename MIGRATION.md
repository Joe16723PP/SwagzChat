# SwagzChat

The Angular 8 client and the Firebase project are gone. The app is the Angular 22 client in `web/` and the Node service in `server/`. Chat is stored in MongoDB. A guest enters with a name. There is no email or Google sign-in. The client styles use Tailwind CSS. Angular Material is gone.

## Still open

- Playwright for name entry, sending a message, and opening a thread
- Calls
- Attachments
- Read cursor, replies, and reactions
